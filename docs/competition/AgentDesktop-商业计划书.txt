一、项目概述

Agent Desktop 是一款面向软件开发者的本地 AI Agent 桌面 IDE。产品将自然语言对话、代码编辑、工具调用与工作区管理整合在同一桌面环境中，通过 Spring Boot Agent 引擎驱动「读代码—改代码—执行工具—分析文档」的完整闭环。

解决的核心问题：

（1）现有 AI 编程工具多依赖云端，代码与文档出域风险高；

（2）国内多模型并存，开发者缺乏统一的 Agent 客户端；

（3）PDF、图片等多模态资料与 Agent 工作流难以协同。

一句话定位：可私有化部署、对接多模型网关的本地 Agent IDE，对标 Claude Code / Cursor 体验，适配国内 CPA 等多模型路由生态。


二、市场分析

2.1 市场规模与趋势

全球 AI 编程助手市场快速增长，从代码补全向 Agent 式开发演进。国内企业研发数字化投入持续增加，对数据安全、内网部署、多模型选型需求明确。高校、园区、创客赛事对 AI 开发工具实训与国产化替代关注度提升。

2.2 目标用户

独立开发者与小团队：需要高效 Agent 编程、低成本多模型切换。

企业研发团队：需要本地部署、权限审计、代码不出域。

高校与培训机构：需要 Agent IDE 实训、竞赛、课程实验环境。

网关与模型服务商：需要配套客户端，形成「网关 + IDE」组合方案。

2.3 竞争与差异化

国际产品（如 Cursor、Claude Code）：体验成熟，但云端依赖强、国内模型接入不便。

国内 IDE 插件类产品：偏代码补全，Agent 工具链与多模态文档能力较弱。

Agent Desktop 差异化：本地 Agent 引擎 + CPA 网关 + 多模态 PDF/图片链路 + 可扩展 MCP，兼顾体验与可控性。


三、产品与服务

3.1 产品架构

Electron 桌面端（Vue 3 + Pinia + Monaco 编辑器）
        ↕ WebSocket / NDJSON 流式协议
Spring Boot Agent 后端（Java 21 + MyBatis + MySQL + Redis）
        ↕ OpenAI 兼容 API
CLIProxyAPI 等多模型网关 → Claude / DeepSeek / GPT 等上游模型

3.2 核心功能

（1）Agent 对话与流式输出：支持多轮规划、工具调用、权限确认。

（2）原生 tool_calls 工具链：read_file、grep、写文件、终端、Git 状态感知等。

（3）多模态文档处理：图片内联、小 PDF 文档块、大 PDF 分页 read_file 提取。

（4）会话管理：checkpoint 回滚、历史记录、项目规则注入。

（5）扩展能力：MCP 服务、Hooks、插件化扩展。

（6）企业向能力（规划中）：审计日志、SSO、策略化权限管控。

3.3 技术壁垒

自研 Agent 循环与工具执行框架，对齐 Claude Code 范式。

与 CPA 网关深度适配，统一走 /v1/chat/completions 与原生 tool_calls。

多模态与 PDF 分页读取链路自研，非简单 API 封装。


四、商业模式

4.1 收入模式

社区版 / 开源核心：获取开发者用户与口碑。

企业版订阅：SSO、审计、私有部署、定制工具与 SLA 服务。

生态合作：与 CPA 等网关联合交付「网关 + 客户端」方案。

教育授权：高校、园区、赛事批量授权与实训支持。

4.2 定价思路（草案）

个人专业版：按年订阅。

企业版：按席位计费，私有化部署另加价。

教育版：批量优惠或公益授权。
