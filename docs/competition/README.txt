参赛材料目录

本目录包含 Agent Desktop 创新创业赛事用的 Word 友好纯文本，可直接用 Word / WPS 打开编辑后导出 PDF 上传。

文件说明：

AgentDesktop-商业计划书.txt  — 必传：商业计划书正文（建议导出为 PDF，≤50MB）
AgentDesktop-补充材料.txt      — 选传：表单文案汇总 + 技术说明 + 截图清单

使用步骤：

1. 用 Word 打开 .txt 文件（或复制粘贴到新文档）
2. 补充团队真实成员、融资金额、截图到附录
3. 排版：封面 + 目录 + 正文（建议 15～25 页）
4. 另存为 PDF
5. 在报名系统「02 附件上传」处上传
