# 我写了一个 AI 编程助手，因为它应该是我自己的工具

> 这篇文章想跟你聊聊，为什么在已经有 Cursor 和 Claude Code 的情况下，我还是决定自己从零写一个 AI 编程工具。

---

## 不是好不好用的问题

Cursor 好用吗？好用。

Claude Code 好用吗？好用。

那我为什么要自己再写一个？

不是因为它比别人好用。v0.1.0 现在肯定打不过打磨了两年的产品。

是因为：**我想拥有它。**

---

## 工具和你的关系，只有两种

第一种：你用别人的工具。

它更新什么功能，你就用什么功能。它改了什么策略，你只能接受。它收费了、涨价了、停服了、被收购了，你没有选择。你的工作流建立在别人的产品上，地基不稳。

第二种：你拥有自己的工具。

它有什么功能，你说了算。你觉得缺什么，你加。你觉得什么东西不该存在，你删。它的边界由你定义，不是由某个产品经理定义。

大部分程序员一辈子都在为别人写代码。但如果能为自己写一个每天用的核心工具，这件事本身就值得做。

---

## Agent Desktop 不是什么

先把它不是的说清楚：

**它不是一个比 Cursor 更注重隐私的工具。** 调大模型的时候，该发给大模型的代码还是得发，这一层没有魔法。

**它不是一个比 Claude Code 更聪明的 Agent。** 大模型是同一些大模型，聪明程度上限是一样的。

**它现在没有比竞品更好用。** v0.1.0，实话实说，打磨程度差得远。

---

## 那它是什么

它是一个**你自己的桌面 Agent 框架。**

桌面应用本身是你写的。Agent 引擎是你写的。怎么调用大模型、怎么执行工具、怎么管理会话，所有的运行逻辑都在你自己的代码里。

它自带代码编辑器、内置终端、文件管理。打开就能用，不需要装插件、不需要配环境。

它的工具体系是开放的。你觉得缺一个自动生成测试的工具？写一个，挂上去。你觉得想集成你公司的内部代码规范检查？写一个，挂上去。

它是你的，不是别人的。

---

## 一个具体的场景

假设你是一个小团队的技术负责人。

你用了某个 AI 编程工具一年。突然有一天，它宣布：免费版不再支持项目级上下文，要用得付费。你的团队有 8 个人，每人是每个月 20 美元。

你怎么办？迁移？你所有的工作流、快捷键、配置、习惯，都在那个工具里。

但如果你的团队用的是 Agent Desktop：

它的能力来自你配置的大模型，用的哪家的 API、什么套餐，你决定。它的功能来自你挂载的插件，你需要什么就装什么，不需要什么就不装。

它不会突然涨价，因为它的价格取决于你选的模型而不是它。它不会突然停服，因为它跑在你自己的电脑上。它不会被收购后改成你不喜欢的样子，因为它的代码在你手里。

## 最后说句实话

我不是在卖产品。Agent Desktop 是开源的，不收费。

我写它，是因为我想拥有自己每天用的编程工具。不是因为别人做得不好，而是因为这件事本身就值得做。

写代码的人，应该有能力给自己造工具。

如果你也这么想，来看看。一起写。
